Error pill no longer covers your code bug fix

Today the pill's anchor measures the newline character, which renders at the start of the next line — so it gets roughly zero and lands on top of your text.

Fix: anchor on the last real character of the line plus a gap, and if it would run off the screen, wrap it to the right edge with reserved padding. The ⊕2 badge stays for lines with several problems.

Press Show the bug at the top to compare.

Block editor biggest item

Full drag-and-drop that writes back to the source, always in sync with the text editor. Kotlin is chopped into class → method → statement; anything the analyzer can't structure falls back to one block per line.

Good news: your analyzer already builds the tree this needs — SymbolTable.root holds scopes with kind, name, start/end and children. This is a walk of an existing structure, not new parsing.

Lives in the full editor area, or in the strip when a panel is beside it.

Scope risk: cutting and re-pasting source ranges while keeping braces and indentation correct is fiddly, and it is the one feature where a bug could damage a file. It ships behind a test that round-trips a file through a reorder.
