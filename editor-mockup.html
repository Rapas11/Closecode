What we agreed

21 answers. Tell me which ones look wrong in the drawing above.

Top bar☰ at the far left. Project name kept. Save, Undo, Redo, Run kept. No search icon.
TerminalMoved out of the top bar into the ⋯ menu, so it is one tap from the top.
Breadcrumb lineUnchanged. File path on the left, Code / Blocks / Preview on the right.
Suggestions4 items instead of 5. Each row: name on the left, type on the right, package underneath.
Signature helpBox above the line, the word you are on is highlighted, one line of description. Unknown words leave the line blank so the box never resizes.
MarginWider, so the coloured bar and the lightbulb both fit. Costs about 12 dots of code width.
Left marginGreen, blue and red bars for changed lines, then the red error bar, then the lightbulb, then the number.
Error fixThe round dot was landing on top of 3-digit line numbers from line 100 up. Fixed.
BracesA short line under the opening { and under the closing }. The box around them is gone.
Side guidesKept faint, and the amber one that lights up the block you are inside stays.
Error pillUntouched. Still at the end of its own line, tap for the full message.
Auto-indentEnter after { moves in by your Indent size. Enter after } comes back out. The } drops to its own line. The switch works on a physical keyboard too.
Symbol row" < > added — outlined in blue.
Word wrapThe switch on the settings screen finally works. The underline, pill and guides now measure the whole logical line so they stay in the right place.
Selection barCut Copy Paste Comment Format, in that order. The one Android draws itself no longer appears.
SearchTwo switches added: match capitalisation, and patterns. Patterns start switched off.
FoldingChevrons down the margin. Tap to collapse any block, and the imports fold as one block. Line 3 shows ▸, the open blocks show ▾.
HTMLBoth templates now say your project name, and the page is richer so Preview shows something worth looking at. Plus tag colours, tag help, and a warning on an unclosed tag.
MoreTap a word and its other uses light up. Long-press a symbol for its name and type. Scrollbar gets small ticks where the errors are. Rainbow brackets exist but start switched off. The function name pins to the top once its opening line scrolls away.
Coming laterProblems / Terminal / Output panel above the bottom bar. Branch name plus changed-line bars. Bottom Search / AI / More bar stays exactly as it is.
Not builtThe Typing / Selecting buttons. They are controls for switching between these two drawings, not a real feature.
